# 可编辑的旋转椭圆

[English](README.md)

打开 `shapes.png`，可看到通用的四边形、原生椭圆和多边形示例。
选中椭圆后显示八个缩放柄、独立旋转柄和完整宽高／角度参数栏。

## 创建与编辑

- 使用 **Shift+E**，拖出控制框的对角线，或分别点击两个端点。
- 拖动角柄或边中点柄缩放，对侧柄保持固定；Shift 拖角柄保持轴长比。
- 拖动圆形旋转柄旋转；Shift 按最终宽度轴角度的 15°整倍数吸附。
- 数值输入结束编辑后提交，Esc 取消未提交输入；一次拖动或一次数值
  提交各形成一次撤销。复制、粘贴、复制副本和撤销后使用当前实际对象。
- 锁定、隐藏、分组、自动保存、切图及自动标注追加／替换沿用软件规则。
  画笔改形、顶点编辑和轮廓合并需要先明确执行“椭圆→多边形”。

语言默认值和用户语言选择沿用上游，新增功能不强制中文或改变模型输出。

## 统一边数设置

“设置 → 画布 → 椭圆拟合边数”默认 **128**，允许 **12–512** 的整数。
预览、分割导出、形状转换和内置 Segment 数据准备共用该值；修改边数
不会重写原生椭圆。

```yaml
canvas:
  ellipse:
    polygon_points: 128
```

CLI 的 `convert` 提前入口也会加载和校验应用配置。优先级为：显式
`--ellipse-polygon-points` → 所选配置文件 → 默认 128。

```bash
python -m anylabeling.app convert --task xlabel2yolo --mode segment \
  --images examples/rotatable_ellipse \
  --classes examples/rotatable_ellipse/classes.txt \
  --output /path/to/separate/ellipse-yolo \
  --ellipse-polygon-points 128
```

用 `--config` 选择 YAML 文件，或用 `--work-dir` 指定用户配置目录。
GUI 启动也接受边数参数。拒绝布尔值、浮点数、配置中的数字字符串和
范围外数值，不静默截断或回退。

## 原生协议与兼容范围

`shape_type="ellipse"` 保存四个有序矩形控制框角点及 `direction`。
零角度时顺序为局部左上、右上、右下、左下；旋转后不按屏幕位置重排。
第一条边表示完整宽度轴，第一点到第四点表示完整高度轴；宽度不必是
长轴，近圆形不自动交换轴。图像 x 向右、y 向下，方向为宽度轴顺时针
弧度 `[0, 2π)`。保留 180°／360°参数方向，不因轮廓等价而重排角点。

中心、轴长和角度统一由角点推导，编辑柄不写入 JSON。已有方向字段
必须是有限数值，布尔值、字符串、null 和非有限值均非法。缺失方向时
推导；有限但不同步时按角点修正并报告文件与对象。读取本身不触发保存。
检查最小轴长、顺序、正交性、对边和对角一致性，不自动修复非法框。
控制框角点越界不等于椭圆轮廓越界。具体容差见英文协议说明。

支持读取合法 r4 JSON；没有 `ellipse` 类型的旧版本不保证能读取新标注。

| 格式／入口 | 本次行为 |
| --- | --- |
| 原生 XLABEL JSON | 保留可编辑椭圆及元数据 |
| YOLO Seg | 采样、真正裁剪、归一化多边形 |
| COCO 分割 | 保留类别、分组及忽略标签规则；新增轮廓实例按实际轮廓计算面积与 bbox |
| VOC 分割 | 软件既有 polygon XML 扩展，不是标准 VOC 检测格式 |
| MASK 灰度／RGB | 共用轮廓，保持类别优先级及图层顺序 |
| 类别／实例掩膜 | 填充椭圆轮廓，不把控制框填成矩形 |
| 现有 MOTS | 保留 `custom_gt.txt` 自定义中间格式，不是标准 MOTS RLE |
| 内置 Segment 数据准备 | 共用边数、几何和类别映射 |
| 不支持的检测、OBB、姿态、OCR 等出口 | 写入前明确报错，不静默丢弃或自动转外接框 |

椭圆先采样再与连续图像区域 `[0,width]×[0,height]` 求交，裁剪后的
点数可变化；清理重复点和冗余边，拒绝完全图外或退化结果。像素掩膜
仍使用有效数组索引及原有栅格化约定，不要求与 Qt 抗锯齿逐像素相同。

已有 polygon 语义保留。新增支持的 quadrilateral 沿用既有逐点限制规则，
范围为 `[0,width−1]×[0,height−1]`，保持顺序，未越界时仍为四点。
这与椭圆采用的真正裁剪规则有意区分，以控制兼容改动范围。

COCO 中纯既有 polygon 实例保留上游栅格面积和像素 bbox 规则；含椭圆
或新增四边形的实例按实际导出轮廓并集计算连续面积和 bbox。原生形状
转换使用完整椭圆采样，不做图像裁剪，保留元数据并清理方向字段。
外部分割格式导入后保持为 polygon，往返不能恢复原生椭圆参数。

## 近似精度与失败保护

均匀参数采样的多边形面积与椭圆面积比为
`N*sin(2π/N)/(2π)`。12、64、128、512 点的理论面积损失分别约为
4.507%、0.1606%、0.04015%、0.002510%。低边数允许合理近似误差；
很小的越界可见部分可能需要提高边数才能避免裁剪退化。

整批输入预检通过后才提交输出；禁止预先清空目录。每个输出先完整
写入同目录临时文件并检查相关源哈希，再安全替换。失败保留旧文件；
取消时保留成功结果，未处理目标不变。这里只保证逐文件安全，不提供
整批或多文件格式的事务性回滚。GUI／CLI 分别报告成功、失败、跳过、
未处理及原因；CLI 取消或失败返回非零状态。请选用独立输出目录。

示例为合成几何图，不包含训练权重或业务数据。已执行检查、官方基线
失败及未执行平台详见[验收报告](../../docs/en/rotatable_ellipse_validation.md)。
